# Planeación Ágil (Scrum Simplificado) — Gestor de Tareas

## Product Backlog (Historias de Usuario)

### Sprint 1 (Semana 2) — Funcionalidades Base

- **HU1:** Como usuario, quiero crear una tarea con título y responsable para registrar un nuevo pendiente.
- **HU2:** Como usuario, quiero consultar la lista total de tareas para ver lo que está registrado.

### Sprint 2 (Semana 3) — Edición, Eliminar y Filtros

- **HU3:** Como usuario, quiero editar una tarea existente o cambiar su estado a "en progreso" o "hecha".
- **HU4:** Como usuario, quiero eliminar una tarea por su ID cuando ya no se necesite.
- **HU5:** Como usuario, quiero filtrar tareas por estado o por responsable para encontrarlas rápido.

### Sprint 3 (Semana 4) — Pruebas y Despliegue

- **HU6:** Como usuario, quiero que el sistema valide campos vacíos y me devuelva errores claros (400, 404).
- **HU7:** Despliegue de la API en Render y entrega final del proyecto.
